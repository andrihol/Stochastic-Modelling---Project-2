
# Stochastic Modelling

Academic project completed as part of
TMA4265 – Stochastic Modelling at NTNU
(Fall 2026).

## Project Overview

This project explores stochastic modelling
through mathematical analysis and computational
simulations.

The project focuses on two main topics:

### 1. Queueing Theory
- M/M/1 queueing systems
- Poisson arrival processes
- Birth-death processes
- Priority-based patient queues
- Monte Carlo simulation
- Confidence intervals

### 2. Gaussian Processes
- Gaussian process regression
- Conditional mean and covariance
- Prediction intervals
- Probabilistic modelling
- Climate model parameter calibration
